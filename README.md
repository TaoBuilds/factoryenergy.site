# MEM 2027 练题站

[打开练题站](https://www.factoryenergy.site/)

面向 2027 年 MEM 在职备考。站点提供 199 管理类综合能力和英语二知识点、客观题练习、解析和错题复盘。进度和错题保存在当前浏览器中。

- **管综 199**：数学、逻辑
- **英语二**：词汇、完形填空、阅读理解

站点由 Hexo 生成，题库在 `source/exam-data/`，练习页在 `source/practice/`。

## 本地预览

```bash
npm ci
npm run server
```

打开 <http://localhost:4000>。运行 `npm run build` 可生成静态站点。
